# Examples

## MCP Client Configuration

Use `mcp_config.json` as a template for connecting to this server from
MCP-compatible editors (Windsurf, Cursor, Hermes Agent, etc.).

```json
{
  "mcpServers": {
    "postgres-new": {
      "url": "http://127.0.0.1:8000/mcp"
    }
  }
}
```

Edit the `url` to match your server's address and port.
